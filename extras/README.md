# Social App

This is a simple Android app created in the main project folder.

## What it does
- Lets the user choose a language from a spinner
- Displays a welcome message in the selected language
- Works as a clean starting point for a social-media app idea

## Files to open in Android Studio
- `settings.gradle.kts`
- `build.gradle.kts`
- `app/build.gradle.kts`
- `app/src/main/java/com/example/socialapp/MainActivity.kt`
- `app/src/main/res/layout/activity_main.xml`

## Steps to run
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Connect an Android phone or start an emulator.
4. Press Run.

## Language choice
The app currently supports:
- English
- Español
- Français
- हिन्दी

This is a starting point you can expand with login, feed, chat, or social content features.
